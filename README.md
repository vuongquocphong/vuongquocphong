## Hi there 👋

I'm **Phong (Phil) Vuong**, a **Product Engineer** at **PostCo**, where we build post-purchase tools for Shopify merchants: returns, exchanges, order editing and sizing. I studied **Computer Science** at the **University of Science, VNU-HCM**.

I like owning a product from the first sketch to the merchant using it: writing the flows, designing the data model, building it, and testing it on staging until it feels right.

- 🔭 **What I'm working on**
  - A **size chart and fit product** for Shopify stores, built end to end: data model, product sync and matching, chart editor with version history and restore, imports, unit conversion, and the size guide shoppers see
  - A **shopper behaviour service** that records shopping journeys and handles privacy deletion requests
  - An **internal AI agent** that picks up Linear tickets, investigates, plans, and opens pull requests for the team, built on [Mastra](https://mastra.ai)
  - Earlier: order editing, analytics, and payment and refund flows on PostCo's main Rails platform

- 🤖 **How I work**
  - AI agents do much of the typing; I own the design, the review, and the result
  - Every PR gets an agent review before a human sees it, and repeated review findings become checks the agents run next time
  - Small PRs, clear write-ups, and testing the edge cases: Back during a save, another tab, Undo after it expires

- 🌱 **What I'm learning**
  - Product judgment: deciding what to build, not only how
  - Planning larger features across people, agents, and dependencies
  - Reliable agent workflows: state, checkpoints, and recovery when a run fails halfway

- 💻 **Tech I use**
  - **Backend:** Ruby on Rails, PostgreSQL, background jobs, REST and GraphQL APIs
  - **Frontend:** React, TypeScript, Inertia, Vite, Tailwind, shadcn/ui
  - **Shopify:** Admin GraphQL API, webhooks, theme app extensions, Web Pixels
  - **Infra:** Cloudflare (Workers, R2), Northflank, Render, GitHub Actions
  - **AI tools:** Codex, Claude Code, Conductor, Mastra
